# 日本語 Grammar Quest  
### Interactive Japanese Grammar Reviewer – Lessons 36–78

A fun, game-based website to master the grammar points from **Lessons 36 to 78** of a complete Japanese grammar course.

## Features

- **Drag & Drop Order** – Rearrange scrambled words into natural Japanese sentences  
- **Find the Incorrect** – Spot the wrong conjugation or pattern  
- **Fill the Blank** – Type the correct conjugated form  
- **Conjugation Puzzles** – Match, fill and quiz every major conjugation:
  - Potential form (可能動詞)
  - Volitional form (意向形)
  - ば Conditional
  - Passive (受身)
  - Causative (使役)
  - Imperative & Prohibitive
  - てしまう / ておく / てある
  - Keigo (尊敬語・謙譲語)

- Score & streak tracking (saved in browser)
- Clean modern UI inspired by card-based design systems
- Fully offline – no build step required

## How to run

Just open `index.html` in any modern browser, or serve the folder:

```bash
npx serve .
# or
python -m http.server 8000
```
